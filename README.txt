UNKOOL WEBSITE

1. Open index.html in a browser to preview the website.
2. To activate WhatsApp enquiries, open index.html in a text editor.
3. Find: const phone='91XXXXXXXXXX';
4. Replace it with your WhatsApp number including country code, without + or spaces.
   Example format: const phone='919876543210';

This is a front-end starter website. It does not yet include online payments, inventory,
shipping integration, or a backend. Product starting prices are editable in index.html.
